# Neural Network for MNIST Classification

## Overview
This project implements a Multi-Layer Perceptron (MLP) neural network from scratch using NumPy to classify handwritten digits from the MNIST dataset.

## Features
- Neural network implemented from scratch
- Forward and backward propagation
- Gradient descent optimization
- Comparison of activation functions (ReLU, Sigmoid, Tanh)
- Hyperparameter tuning and performance evaluation

## Technologies
- Python
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
The project uses the MNIST handwritten digits dataset.

## Results
The model was trained and evaluated on MNIST, achieving strong classification performance while demonstrating the fundamentals of neural network training and optimization.
